Put your copy of the iPad game here
===================================

This folder is empty on purpose: the PC port comes without any game files.  Copy the contents of the
GTRacingFreemiumHD.app folder from your own copy of the iPad game (GT Racing: Motor Academy Free+ HD,
version 1.3.4b) into this folder.

When it is right, this folder holds the game's program file next to its data, for example:
    GTRacingFreemiumHD.app\GTRacingFreemiumHD      (the game's program, a file with no extension)
    GTRacingFreemiumHD.app\Info.plist
    GTRacingFreemiumHD.app\...                     (the rest of the game's files and folders)

An .ipa file of the game is a zip archive: the folder is Payload\GTRacingFreemiumHD.app inside it.

If gtracing.exe says the folder has no game in it, the files are not in the right place.  A copy one level
too deep (GTRacingFreemiumHD.app\GTRacingFreemiumHD.app\...) is found as well.

You can delete this note once the game is in.
